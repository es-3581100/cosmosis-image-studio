// PROVIDER ADAPTER

OPENAI

Images API + Responses image-generation tool. User and provider-revised prompts remain separate.

ContractCredentialsValidationFailure

Canonical contract

UI code never constructs provider wire formats. The adapter translates a validated canonical request.

Credentials

Read from OPENAI_API_KEY. Keys are never persisted into projects or reports; displayed diagnostics must use redacted fingerprints.

Validation

Check model capabilities, masks, reference count, MIME, dimensions, aspect ratio, quality and output format before network I/O.

Failure / fallback

Return an actionable provider error and preserve the failed durable job. Do not automatically switch provider unless the user's explicit fallback policy allows it.
