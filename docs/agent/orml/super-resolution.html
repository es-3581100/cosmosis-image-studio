The backend reproduces ORML's luminance/chroma conversion and nearest-neighbor 2× Pb/Pr preparation without OPENGL. One graph octave doubles width and height. ServiceLoader admission requires the exact model plus a working TensorFlow Java/native runtime.

Performance

High local inference for large assets; GPU recommended.

Editor integration

Create a non-destructive UPSCALE child version. The normal editor path requests one 2× octave; the runner accepts up to three octaves while enforcing a neural pixel budget. Source assets are never overwritten.

Worker integration

Primary role: EXPORT.WORKER. Invocation must stay inside job budgets and be cancellable where the external runtime permits.

Common mistakes

Never overwrite the source. Inspect hallucinated texture/detail before final export.

Fallback behavior

If the pinned FALSR model or TensorFlow Java/native runtime is absent, the backend fails ServiceLoader admission and super-resolution remains unavailable. Do not silently substitute a cloud provider or relabel the deterministic local bicubic upscale as FALSR output.

Source / provenance

The graph and color-conversion contract are grounded in pinned openrndr/orml super-resolution source plus its SHA-256-pinned FALSR-A model. No ORML implementation source is copied. See orml-runner-super-resolution/runtime-manifest.json for the machine-readable runtime pin.
