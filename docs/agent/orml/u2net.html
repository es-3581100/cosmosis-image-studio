Performance

Editor integration

Background removal, smart subject selection, outpainting preparation. Outputs remain derived metadata/assets.

Worker integration

Primary role: MASK.WORKER. Invocation must stay inside job budgets and be cancellable where the external runtime permits.

Common mistakes

Do not assume every foreground boundary is semantically correct. Inspect hair, transparent objects and fine edges.

Fallback behavior

If the pinned model or TensorFlow Java/native runtime is absent, the U2Net backend fails ServiceLoader admission and the runner reports this capability unavailable. The editor may use its explicitly labeled deterministic local saliency fallback, but must not claim that output is U2Net/ORML inference.

Source / provenance

Capability and graph contract are grounded in pinned openrndr/orml U2Net source and its SHA-256-pinned model. No ORML implementation source is copied. The backend independently implements the preprocessing and TensorFlow graph invocation with Java image buffers so the isolated runner does not require an OPENGL context. See orml-runner-u2net/runtime-manifest.json for the machine-readable pin.
