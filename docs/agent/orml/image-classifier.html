Performance

Low/medium local inference.

Editor integration

Search, prompt recommendations and reference grouping. The backend emits full embedding values plus top ImageNet class indices/scores as generated metadata. Label names are intentionally not bundled, and generated metadata remains separate from user-authored tags.

Worker integration

Primary role: VISUAL.ANALYZER. Invocation must stay inside job budgets and be cancellable where the external runtime permits.

Common mistakes

Generated tags must remain separate from user-authored tags.

Fallback behavior

If the pinned model or TensorFlow Java/native runtime is absent, the classifier backend fails ServiceLoader admission and image-embedding remains unavailable. Do not silently substitute a cloud provider, fabricate embeddings, or promote numeric class metadata into user-authored tags.

Source / provenance

The graph contract is grounded in pinned openrndr/orml classifier source and its exact bundled model Git blob. No ORML implementation source or ImageNet label-name table is copied. The TensorFlow graph invocation and preprocessing are independently implemented in the isolated runner. See orml-runner-classifier/runtime-manifest.json for the machine-readable pin.
